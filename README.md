# 个人主页

段杰的 GitHub Pages 个人主页。蓝色纸面、细线分栏与响应式排版，包含项目实践、创业实践、科研探索、比赛奖项、专业技能和个人介绍。

## 内容维护

修改 `content.js`：`sections` 保存经历，`details` 是完整说明，`highlights` 是页面摘要，`facts` 是有明确口径的数字。VESTI 的性能指标属于团队产品评测；G01 数据仅代表该批次；论文处于计划撰写与标注准备阶段。

`skills` 保存技术列表；`email`、`education`、`degree`、`availability` 保存联系与教育信息。技能名称不表示掌握程度。网页不上传个人简历原文件。

## 交互与预览

搜索框默认显示，支持中文或英文技术关键词、分类筛选及重置；每段经历可打开详情，支持 Escape 关闭。浅蓝 / 深蓝主题选择保存在浏览器本地。

四个网页文件保持在同一目录，可以使用静态 HTTP 服务预览。更新线上时一起提交 `index.html`、`style.css`、`content.js` 和 `script.js`，由现有 GitHub Pages 发布。
